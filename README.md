# COMP3005_A3_Q1

Task: Implement a PostgreSQL database using the provided schema and write an application in your language of choice that 
	  connects to this database to perform specific CRUD (Create, Read, Update, Delete) operations.

Set Up Instructions:
- Install PostgreSQL on your machine if you haven't already. You can download it from the official website: https://www.postgresql.org/download/
- Download pgAdmin, a graphical interface for managing PostgreSQL databases: https://www.pgadmin.org/download/
- Create a new database in PostgreSQL using pgAdmin or the command line.
- In the main.py file, replace the placeholder values for the database connection parameters (host, database name, user, password) 
  with your actual PostgreSQL credentials
- Make sure the students.sql and studentsData.sql files are in the same location as the main.py file, or else they won't be able
  to be executed properly.

To run the application:
- Open a terminal or command prompt.
- Navigate to the directory where the main.py file is located.
- Run the command: `python main.py` to start the application.
- Follow the prompts in the terminal to perform CRUD operations on the database.
- To exit, type "5"
